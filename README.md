# Moodly ✨

An interactive, client-side daily mood tracker and mental health dashboard application. Moodly provides users with an intuitive platform to document personal emotional metrics, log sleep cycles, view real-time data distribution analytics, and track contextual daily logs through a modern, responsive user interface.

## 🛠️ System Features

### 1. User Authentication System
* **Interactive Registration System:** Validates new sign-ups by checking against existing data arrays via `localStorage` to catch duplicate usernames. 
* **Dynamic UI Transitioning:** Smooth layout shifting between Sign-In and Sign-Up panels inside a centralized container module using vanilla CSS modifiers.

### 2. Analytical Interactive Dashboard
* **Dynamic Trend Visualization:** Formulates custom scalable graphic line charts dynamically utilizing mathematical coordinates generated instantly through structural SVG vectors (`<circle>`, `<path>`) mapped directly out of persistent client-side tracking chronological sets.
* **Real-time Distribution Profile:** Evaluates total logged states instantly to map percentage distributions across varying emotional profiles, reflecting changes via real-time linear progress bars.
* **Sleep Rest Tracking:** Parses automated descriptive arrays (`Sleep: Xh`) to generate structured historical vertical bars tracking sleep durations against ideal thresholds.
* **Chronological History Log:** Generates comprehensive records of past events in reverse-chronological order. Features localized modular removal triggers (`data-index` splice tracking) allowing instantaneous data updates.
* **Automated Continuity/Streak Monitor:** Evaluates precise calendar gaps by converting alphanumeric data strings (`DD/MM/YYYY`) into operational Unix epoch timestamps to compute continuous check-in streaks dynamically.

### 3. Structural Calendar Interface
* **Dynamic Grid Population:** Builds automated monthly views natively from standard JavaScript `Date()` pointers, properly handling month offsets and varying leap-year end bounds.
* **Visual Historical Identifiers:** Matches chronological keys directly to individual cell elements, instantly overlaying the specific day's tracked emoticons directly onto the calendar layout grid.
* **Modular Daily Memo Pad:** Feature that lets users click tracked days to instantly recall timestamps, metadata logs, and contextual descriptions on an analytical sidebar UI container.

## 🧪 Credentials & Instructions to Test Login

Since the application operates purely on browser client-side storage (`localStorage`), you can register any new custom credential set directly on the portal, or leverage the following default automated setup steps to test the full operational dashboard capabilities:

### Step-by-Step Test Procedure:
1. Open the live deployment link in any modern web browser.
2. If you do not have an active local profile, click **Sign Up** on the authentication card interface.
3. Input a test user profile name (e.g., `Masyitah`) along with any chosen placeholder credential pass phrase.
4. Click **Register**—the system will alert you that registration was successful and slide you back to the login screen.
5. Provide your matching credentials on the **Sign In** interface block to instantly unlock the core data dashboard panels.
6. Navigate to **Daily Check-in** to log immediate mood data, intensities, or hours of sleep. Submit the form, then review how the metrics instantly populate your **Dashboard** and **Calendar** interfaces without code-refresh deletion bugs.

## 🧰 Frameworks & Libraries Used

This platform is structured entirely with standard native core web modules to minimize dependency bloated overheads, ensuring rapid viewport optimization and fast loading speeds:

* **HTML5 Structure:** Provides semantic architecture across all core modules (`index.html`, `dashboard.html`, `calendar.html`, `check-in.html`, `resources.html`, `about.html`).
* **Vanilla CSS3 Flexbox & Grid Elements:** Manages structural responsive properties, adaptive text-wrapping across varying viewports, sidebar layout constraints, layout alignments, and smooth transition animations.
* **Pure Client-Side Vanilla JavaScript (ES6+):** Executes core logical functionalities, dynamic SVG point calculations, array splicing triggers, dynamic local storage caching workflows, object state validation procedures, and DOM construction algorithms.
* **Boxicons Web Vector Suite (`v2.1.4` via CDN):** Delivers clean vector interface typography iconography layouts throughout global dashboard panels and structural sidebar navigation controls.
* **Google Fonts API Web Integration:** Loads clean typography families (`Nunito`) to provide an aesthetically pleasing, modern layout.
